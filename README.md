# 🎮 Arcade Achiever

A gamified task management system combining web app and IoT for enhanced productivity.

[ESP32 Companion Repository](https://github.com/simmacos/Thesis-ESP32)

## Features

- Task management with gamification elements
- Points and leveling system
- AI-generated side quests
- Real-time IoT device integration
- Progress tracking dashboard

## Tech Stack
- HTML
- CSS (tailwind)
- Vue.js 
- Flask (Python)
- MariaDB
